# Agent Harness Builder

基于 QQ 音乐 [Harness Engineering 实践](https://mp.weixin.qq.com/s?__biz=Mzg4Nzc3MjA3Nw==&mid=2247483813&idx=1&sn=97b4b487b571c4ab394e4ad5a6dd4b4f) 理论构建的 Agent 装配台。

## 功能

- 6 个角色的 Harness 管线（内容创作 / 开发 / 产品 / 运维 / 运营 / 数据）
- 每个角色 5 阶段管线 + 强制门禁
- 39 个 Skill 按阶段节点装配（含推荐默认值 + 外部运行时工具）
- 生成完整 MD 配置（管线图 + 阶段明细 + 安装命令 + Skill 清单）
