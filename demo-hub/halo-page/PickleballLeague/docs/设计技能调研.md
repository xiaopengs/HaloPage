# 设计技能调研与采用决策

本次调研聚焦两个可复用的前端设计技能。Taste Skill 的公开说明将其定位为面向 AI 编程代理的反模板化前端框架，强调从设计简报推断方向、在重构任务中先审计、建立设计系统并执行交付前检查 [1]。Impeccable 的公开设计流程则将工作拆为“设定上下文、改进现有界面、交付前检查、持续维护”四段，并把可访问性、性能、主题、响应式和反模式纳入交付前审查维度 [2]。

| 技能 | 适合解决的问题 | 本项目的采用方式 |
| --- | --- | --- |
| Taste Skill | 防止界面落入模板化卡片、泛化渐变和弱信息层级；从简报中形成完整视觉方向。 | 采用其“先读简报、再建立设计系统、重构先审计”的思路，服务于赛事编辑部风格和反玻璃拟态重构。 |
| Impeccable | 将产品与设计上下文沉淀为文档；在交付前逐项检查响应式、可访问性与设计漂移。 | 采用其“上下文—重构—审查—维护”流程；本目录的需求、方案、交互文档即为本次上下文基线。 |

本项目不把外部技能的安装脚本作为产品运行时依赖，也不将其内容混入业务代码。它们只服务于设计方法和审查流程；最终网页仍是无后端、可部署的静态页面。
