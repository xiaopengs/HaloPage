# NiuMa Cheer · 牛马鼓励器

一个把「今天也在好好搬砖」算成实时收入的小页面：上班时秒针一跳，今日已赚就往上走；小驴在卡片里追着萝卜原地踏步，永远只差一点点。单文件 HTML，无外部依赖。

![牛马鼓励器](preview.jpg)

界面按一段手机录屏重建，保留了原版的排版和信息密度，并补齐了原视频里看不到的设置与专注模式。

## 功能

- **实时收入**：按上班 / 午休 / 下班自动计算工时与今日收入，上班时精确到小数点后四位持续跳动，午休和下班自动冻结。
- **状态与倒计时**：上班中、午休中、还没上班、下班了、周末快乐五种状态，倒计时精确到秒。
- **小驴追萝卜**：纯 SVG 小驴，四条腿和尾巴有独立节奏，胡萝卜在杆子前晃；可随时「暂停」，让小驴和你一起歇会儿。
- **愿望换算**：在设置里写想买的东西和价格，页面会算「再工作多久就够赚『自助烤肉』」，并自动跳到下一个还没攒够的愿望。
- **专注模式**：点「隐藏倒计时 · 专注一会儿」，倒计时换成 25 分钟专注计时，金额被虚化，小驴降饱和；结束或手动退出即恢复。
- **本月累计**：按当月已过的工作日（周一至周五）满勤日薪累加，再加上今日实时收入，与录屏里的数字口径一致。
- **设置**：上下班时间、午休区间、时薪、愿望清单、顶栏常驻，全部存在 localStorage，刷新不丢。
- **响应式**：手机上是整屏卡片，桌面端居中浮起；支持 `prefers-reduced-motion`。

## 操作

- 设置：右上角「设置」，改完保存
- 置顶：让顶栏吸顶，滚动时也能看到状态
- 暂停：小驴面板右上角
- 专注：中间深色按钮，或按 `F`
- 关闭弹层：`Esc` 或点遮罩

## 默认口径

- 上班 09:30，下班 18:00，午休 12:00–13:00，每天 7.5 小时
- 时薪 ¥16，满勤日薪 ¥120
- 本月工作日按当月周一到周五实时统计

录屏里的 16:44:01 对应：距离下班 1 小时 15 分 59 秒、今日 ¥99.7388、进度 83.1%、本月 ¥219.74，本页面按同一套规则可复现。

## 技术

- 单个 `index.html`，约 31 KB，无框架、无构建、无外部请求。
- 原生 JS 计算日程与金额，秒级刷新；SVG + CSS keyframes 做小驴动画；localStorage 持久化。
- 时间、金额、进度都用等宽数字（`font-variant-numeric: tabular-nums`），跳动时不抖。

## 验证

- 390×844 与 1280×800 下无控制台错误，无横向滚动。
- 上班、午休、下班、周末、专注、暂停、设置保存与刷新持久化均已测试。
- 与录屏同一时刻的数据逐项对齐（金额、进度、本月累计、愿望剩余时长）。

## 部署

把 `NiuMaCheer/` 放进任意静态目录，访问 `NiuMaCheer/index.html` 即可；也可以直接双击本地打开。
