# 项目需求说明书

## 1. 项目定位

“赛点青”是为一次六人团建而设计的**本地优先匹克球单打循环赛记录器**。它不是通用赛事管理后台，而是一块服务于现场组织者、参赛者和围观同事的“赛事控制台”：在一部手机或一台平板上，任何人都能看懂今天谁参赛、下一场谁对谁、比分如何录入、积分榜怎样变化，以及赛事结束后谁获得冠军与亚军。

## 2. 固定业务规则

| 维度 | 需求 |
| --- | --- |
| 参赛阵容 | 鹏哥、亮哥、睿哥为男选手；琳姐、寒姐、忱姐为女选手。名单固定，不提供现场编辑。 |
| 赛制 | 六人单打单循环；每两人只交手一次，共 15 场；共 5 轮，每轮 3 场。 |
| 单场计分 | 11 分制；获胜方至少得到 11 分且领先至少 2 分；不允许平局。 |
| 排名积分 | 胜一场记 1 积分，负一场记 0 积分；同时累计得分、失分和净胜分。 |
| 排名规则 | 积分、净胜分、总得分、固定报名顺序依次比较。 |
| 荣誉规则 | 15 场赛果全部录入后，积分榜第 1 名为冠军，第 2 名为亚军；页面可同时呈现季军。 |
| 数据保存 | 使用当前浏览器的 `localStorage` 本地保存；重置仅清除比分，不改动固定名单。 |

## 3. 用户与关键任务

| 用户 | 使用情境 | 必须完成的任务 |
| --- | --- | --- |
| 赛事组织者 | 场边快速录分 | 选对对局、录入正确比分、看见保存成功和自动跳到下一场。 |
| 参赛者 | 等待上场或赛后查看 | 快速确认自己下一场的对手、排名、积分、胜负与净胜分。 |
| 围观同事 | 关注赛况 | 一眼看到当前榜首、已完成场次、正在进行/下一场和最终颁奖结果。 |

## 4. 成功标准

页面必须在桌面和手机上清晰展示比赛状态；任何一次合法比分保存后，赛程、进度、积分榜和领奖台应同步更新。页面不应要求登录、网络接口或培训；首次进入首页应在单屏内看清**赛事规模、核心规则、当前榜首与下一步入口**。

## 5. 约束与非目标

本期不支持多人赛事、双打赛制、在线协作、账号系统或跨设备同步；这些能力不应稀释“六人现场循环赛”的效率。所有呈现的赛事结果必须由真实录入的比赛数据计算，不植入虚构战绩、评价或用户反馈。
