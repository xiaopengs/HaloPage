# 赛点青 · 匹克球循环赛记录器

这是一个**无需后端**的六人团建匹克球单打循环赛记录页面。页面数据通过浏览器 `localStorage` 保存，适合放置在 Halo、1Panel 或 Nginx 的静态目录下直接访问。

## 赛制与数据规则

| 项目 | 约定 |
| --- | --- |
| 人数 | 固定 6 人，报名页要求 3 男、3 女 |
| 赛制 | 单循环单打，每两位选手交手一次，共 `6 × 5 ÷ 2 = 15` 场 |
| 比赛分数 | 默认每局 11 分；比赛录入时不允许同分 |
| 胜负与积分 | 胜场 1、负场 0；排名主序为胜场数，其次为净胜分、总得分、直接交手结果 |
| 冠亚军 | 全部 15 场录入完成后，积分榜第 1 名为冠军、第 2 名为亚军 |
| 本地保存 | 名单、赛事标题与全部比分均写入浏览器本地存储；清空按钮可重置为初始占位名单 |

## 文件结构

```text
PickleballLeague/
├── index.html        # 页面结构与功能分区
├── styles.css        # 暗青玻璃拟态视觉系统
├── app.js            # 本地状态、赛程生成、比分与统计计算
├── README.md         # 规则和部署说明
└── ideas.md          # 参考视频的视觉复刻说明
```

## 部署

将整个 `PickleballLeague` 目录上传至站点静态目录，例如：

```bash
mkdir -p /path/to/site/static/pickleball
cp -r PickleballLeague/* /path/to/site/static/pickleball/
```

随后访问 `https://你的域名/static/pickleball/`。首次打开后，在“球员”页面填写六位参与者信息，点击“保存并生成赛程”即可开始记录。
