# 赛点青 · 匹克球循环赛记录器

这是一个**无需后端**的六人团建匹克球单打循环赛记录页面。页面数据通过浏览器 `localStorage` 保存，适合放置在 Halo、1Panel 或 Nginx 的静态目录下直接访问。

## 赛制与数据规则

| 项目 | 约定 |
| --- | --- |
| 人数 | 固定 6 人：鹏哥、亮哥、睿哥、琳姐、寒姐、忱姐（3 男、3 女） |
| 赛制 | 单循环单打，每两位选手交手一次，共 `6 × 5 ÷ 2 = 15` 场 |
| 比赛分数 | 11 分制；胜方至少得到 11 分且需领先 2 分，比赛录入时不允许同分 |
| 胜负与积分 | 每胜 1 积分、每负 0 积分；排名依次为积分、净胜分、总得分、固定报名顺序 |
| 冠亚军 | 全部 15 场录入完成后，积分榜第 1 名为冠军、第 2 名为亚军 |
| 本地保存 | 固定名单与全部比分均写入浏览器本地存储；清空按钮可清除赛果并保留固定阵容 |
| 赛后海报 | 全部 15 场完成后，在“颁奖”页生成包含冠亚军与完整积分榜的 PNG 图片，可保存或在支持的手机浏览器中调用系统分享 |

## 文件结构

```text
PickleballLeague/
├── index.html        # 页面结构与功能分区
├── styles.css        # 赛事编辑部与现场记分板视觉系统
├── app.js            # 本地状态、赛程生成、比分与统计计算
├── README.md         # 规则和部署说明
├── ideas.md          # 当前设计方向说明
└── test-poster-export.mjs # 浏览器端赛后海报导出回归测试
```

## 部署

将整个 `PickleballLeague` 目录上传至站点静态目录，例如：

```bash
mkdir -p /path/to/site/static/pickleball
cp -r PickleballLeague/* /path/to/site/static/pickleball/
```

随后访问 `https://你的域名/static/pickleball/`。打开后即可从“录分”页开始记录固定六人阵容的赛果；所有 15 场完成后，前往“颁奖”页点击“保存结果海报”。在支持系统分享的手机浏览器中，还可点击“系统分享图片”并在系统面板中选择已安装的分享应用。
