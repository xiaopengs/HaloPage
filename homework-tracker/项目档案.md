# 📋 项目档案：小孩子作业记录网站

- 项目名称与一句话定位：小孩子作业记录网站（Kid Homework Tracker）——面向家长的多孩子作业结构化记录工具：拍照即记、AI 识别、按"每周→每天→学科"一屏掌握
- 平台选型：响应式 Web 网站（家长 C 端，移动端优先，含手机浏览器拍照上传适配）+ 同站 Web 管理后台
- 技术栈：Vue 3 + Vite + Pinia + Vue Router + 自有设计系统“作业夹”（前端，无 UI 框架）；Node.js 22 + Express 5 + node:sqlite（后端，零原生依赖）；JWT 双 Token（access 2h / refresh 7d 哈希轮换）；Qwen-VL（DashScope OpenAI 兼容端点）识别主链路 + 备用 OpenAI 兼容端点 + 手动录入三级降级链；本地 uploads 存储（photo_key 与 OSS object key 同构，可平滑替换）
- 当前阶段：V1.1 已发布上线（作业夹设计系统全量落地，手动批量录入可用，公网链接已验证）

## 关键决策留痕

- 账号主体=家长，孩子为"被记录对象"（儿童隐私合规设计，隐私政策含专章）
- AI 识别必须"预填+人工确认"，绝不自动盲存（验收红线，已实测）
- MVP 不做小程序/App/支付/社交（单端先行）
- 数据库用 node:sqlite 替代 better-sqlite3（二进制兼容问题），生产可平滑换 MySQL（模型按标准 SQL 设计）
- Express 5 通配路由用 `/{*splat}`（path-to-regexp v8 不再支持 `*`）
- 照片归属校验：`key.startsWith('homework/${uid}/')` + 登录态，越权零容忍
- 团长裁决口径：BQ-01 账号密码登录；BQ-02 压缩统一 ≤1MB；BQ-03 识别单次 ≤10s/总上限 30s；BQ-04 沙盒内网交付 + 正式公网 ICP 备案并行
