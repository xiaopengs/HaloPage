# 小孩子作业记录网站 · 视觉设计方案

> 视觉代号：**作业夹**  
> 设计对象：家长使用的多孩子作业记录 Web（移动端优先）  
> 核心任务：一眼看清一周作业分布；用最短路径手动记下当天作业  
> 配套原型：`作业夹-视觉原型.html`（可交互，含手动输入作业框）

---

## 1. 视觉主张：一本会打勾的作业活页夹

不把产品做成“又一个教育 SaaS 后台”，也不刻意做成儿童玩具。视觉语言来自家长真实接触的三样东西：

| 现实物件 | 界面转译 | 作用 |
|----------|----------|------|
| 课程表 | 周看板的日期分区、横向周导航 | 建立“这周每天有什么”的空间记忆 |
| 学科标签 | 六学科固定色彩与小标签 | 扫读时先分科，再读内容 |
| 红笔 | 保存、今日定位、关键确认动作 | 让行动色有产品含义，而非装饰 |

**唯一用力的记忆点**：周看板左侧的大号日期数字。它让家长像翻活页夹一样定位星期；其他区域保持低装饰、低阴影、低饱和。

## 2. 配色系统

### 2.1 基础色

| Token | 色值 | 用途 |
|-------|------|------|
| `paper` | `#F7F9FC` | 页面底色，冷纸白，避免教育产品常见的暖奶油底 |
| `card` | `#FFFFFF` | 输入卡与日卡承载面 |
| `ink` | `#20304A` | 标题、正文重点、日期数字 |
| `slate` | `#66758C` | 辅助说明、空态、次要按钮 |
| `rule` | `#DDE5EF` | 格线、分隔线、输入框边界 |
| `redpen` | `#C84636` | 主按钮、今日标记、保存反馈 |
| `done` | `#238A68` | 完成状态；与勾选图标和文字共同出现，不单独依赖颜色 |

### 2.2 学科色

学科色只用于**分类识别**：标签、作业条目前的小色条、学科选择态，不用于整卡铺色。

| 学科 | 色值 | 标签底色（同色系低饱和） |
|------|------|---------------------------|
| 语文 | `#C4455E` | `#FBECEF` |
| 数学 | `#356FD6` | `#EBF1FD` |
| 英语 | `#7656C9` | `#F1EDFB` |
| 科学 | `#16877A` | `#E7F5F2` |
| 道德与法治 | `#A96F18` | `#FBF3E4` |
| 其他 | `#66758C` | `#EEF2F6` |

### 2.3 使用比例与可访问性

- 约 **80% 纸白与卡片白 / 15% 墨蓝结构 / 5% 学科色与红笔强调**。
- 正文使用 `ink`，辅助文字使用 `slate`；不用浅灰文字承载关键作业内容。
- 红笔按钮使用白色粗体文字；焦点态有 3px 墨蓝外环，不能只靠 hover 表达。
- 完成状态同时具有：勾选符号、删除线、计数变化，色弱用户也能理解。

## 3. 字体系统

| 字族 | 角色 | 字重与用法 |
|------|------|------------|
| **Noto Sans SC** | 全部中文界面文字 | 400 正文 / 500 辅助 / 700 按钮与标签 / 800 页面标题 |
| **Space Grotesk** | 日期数字、周范围、完成计数 | 500–700；数字采用等宽数字特性，形成稳定对齐 |

回退：`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。

### 字阶

| 层级 | 规格 | 使用位置 |
|------|------|----------|
| 展示数字 | 34px / 1.05，700 | 日卡日期；桌面 40px |
| 页面标题 | 24px / 1.3，800 | “这周作业”“记作业” |
| 卡片标题 | 17px / 1.45，700 | 星期、录入卡标题 |
| 正文 | 15px / 1.65，400–500 | 作业内容、说明 |
| 标签与按钮 | 13–15px / 1.4，700 | 学科 chip、主按钮 |
| 辅助 | 12px / 1.55，500 | 日期、计数、输入提示 |

正文行宽控制在 80 字符以内；作业内容不两端对齐，统一左对齐。数字与计数右对齐，中文正文左对齐。

## 4. 版式系统

### 4.1 基础规则

- **8px 间距网格**：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 卡片圆角 16px；输入框 12px；学科标签全圆角。圆角按层级区分，不全局统一。
- 阴影只用于浮层和正在编辑的便签卡；日卡使用 1px 格线，不堆叠灰色阴影。
- 触控目标至少 44px；手机主按钮高度 48px。
- 页面最大宽度 1120px；手机边距 16px，桌面边距 32px。

### 4.2 移动端周看板

```text
┌──────────────────────────────┐
│ 作业夹              大宝 ⌄   │  品牌与孩子切换
├──────────────────────────────┤
│ 这周作业                     │
│ ‹ 上一周   10/19—10/25  下一周 › │
│                              │
│ ┌──────┬───────────────────┐ │
│ │ 24   │ 周六 · 今天  1/2  │ │  日期区固定 64px
│ │ 周六 │ 语文              │ │
│ └──────┤  □ 抄写第 8 课生字 │ │
│        │ 数学              │ │
│        │  ☑ 练习册第 32 页 │ │
│        └───────────────────┘ │
│ ┌──────┬───────────────────┐ │
│ │ 25   │ 周日         0 条 │ │
│ └──────┴───────────────────┘ │
│                              │
│ 看板       ＋ 记作业     孩子 │
└──────────────────────────────┘
```

- 日期是定位锚点， weekday 与“今天”是辅助信息，不与日期数字争夺注意力。
- 每个日卡内部按学科分组；空学科不占位，避免一周视图充满无意义空格。
- 今天仅用红笔小标记和浅色日期底强调，不用整卡高饱和铺色。

### 4.3 手动录入页（本次功能重点）

```text
┌──────────────────────────────┐
│ 记作业                       │
│ 手动输入最稳妥，每行保存为一条 │
│                              │
│ 孩子   [ 大宝 ⌄ ]             │
│ 学科   [语文][数学][英语] ...  │
│ 日期   [2026-10-25] [今天]     │
│                              │
│ ┌ 手动输入作业 ─────────────┐ │
│ │                          │ │
│ │  抄写第 8 课生字          │ │
│ │  背诵课文第 2 段          │ │
│ │                          │ │
│ └──────────────────────────┘ │
│ 每行一条 · 将保存 2 条         │
│ [练习册第_页][抄写第_课][订正错题] │
│                              │
│ [      保存到周看板       ]    │
│ 保存后会归入所选日期和学科      │
└──────────────────────────────┘
```

**交互约定**：

1. 大输入框自动增高，最少 5 行；支持连续输入，每行是一条作业。
2. 空行自动忽略；输入时实时显示“将保存 N 条”。
3. 学科为单选 chip，日期默认今天，可改为本周任意一天。
4. 快捷短语只插入文本，不直接保存；用户始终拥有最终编辑权。
5. 缺少学科或内容时，在对应位置提示“先选择学科”或“先写一条作业”，保存按钮不制造无反馈点击。
6. 保存成功提示“已保存到周看板”，回到对应日期并短暂高亮新条目；文案与按钮动作一致。
7. 拍照识别保留为辅助入口，不抢占手动输入框的首屏位置。

### 4.4 桌面扩展

```text
┌──────────────────────────────────────────────────────────┐
│ 作业夹 / 大宝                  看板  记作业  孩子         │
├──────────────────────────────────────────────────────────┤
│ 这周作业                        ‹ 10/19—10/25 ›          │
│ ┌ 周一 ┐ ┌ 周二 ┐ ┌ 周三 ┐                              │
│ │  19  │ │  20  │ │  21  │   日卡两列/三列排布           │
│ └──────┘ └──────┘ └──────┘                              │
│ 记作业页：左 7 栏手动输入便签 / 右 5 栏本周预览            │
└──────────────────────────────────────────────────────────┘
```

桌面不简单拉宽手机卡片；利用宽度并列日期，但保留同一套日期锚点与学科标签。

## 5. 组件与状态

| 组件 | 默认 | 交互/状态 |
|------|------|-----------|
| 主按钮 | 红笔底、白字、48px 高 | hover 加深 6%；active 下压 1px；focus 墨蓝外环 |
| 学科 chip | 浅底+学科色文字 | 选中时 1.5px 学科色边+勾选符号 |
| 作业条目 | 左侧学科色条、正文墨蓝 | 完成后打勾、删除线、计数同步更新 |
| 输入框 | 白底、`rule` 边、12px 圆角 | focus 墨蓝边+浅底；错误用红笔边与具体提示 |
| 空日卡 | 日期仍在，内容区一行“暂无记录” | 提供“记作业”动作，不用插画填满 |
| 新保存条目 | 正常作业条目 | 2 秒浅底色高亮；`reduced-motion` 下取消 |

非用户触发只有一个克制的入场；不使用全屏卡片浮动、满屏 hover 或装饰性渐变。

## 6. 文案规范

- 按钮说结果：**“保存到周看板”**，而不是“提交”。
- 输入提示说格式：**“每行一条作业，例如：数学练习册第 32 页”**。
- 空态给下一步：**“这一天还没有作业，点‘记作业’添加第一条。”**
- 错误给修复动作：**“先选择学科，再保存作业。”**
- 识别说明不夸大：**“识别结果会预填到输入框，核对后再保存。”**

---

## 7. 自检与克制记录

1. **不是换皮默认款**：底色为冷纸白，主色为墨蓝，行动色来自红笔；没有奶油底+陶土色、黑底荧光色、报纸分栏或 SaaS 卡片套件。
2. **主题来自内容**：日期锚点、学科标签、红笔动作均来自“家长记作业”的真实材料，不是抽象装饰。
3. **只在一处用力**：大号日期数字是唯一强视觉元素；取消了大面积学科铺色、装饰插画与层层阴影。
4. **手动录入是完整闭环**：不是静态输入框；包含学科、日期、逐行拆分、条数预览、校验、保存反馈与看板回写。
5. **质量基线**：移动端优先、桌面响应式、键盘焦点可见、对比度与完成状态多重编码、尊重 `prefers-reduced-motion`。

## 8. 落地实现（2026-10-25 前端全量重构）

本方案已从原型落地到实际应用，不是仅停留在视觉稿：

| 层面 | 实现 |
|------|------|
| 设计令牌 | `client/src/styles/tokens.css`：颜色、字体、圆角、阴影，全部以 CSS 变量提供 |
| 基础样式 | `client/src/styles/app.css`：布局、按钮、表单、学科标签、周看板、录入、弹层、Toast、响应式 |
| 组件 | `BaseModal`、`ConfirmHost`、`ToastHost`、`BrandMark`；移除 Element Plus，全部原生实现 |
| 页面 | 登录、周看板、记作业（新建/编辑）、孩子档案、我的、隐私政策、运营后台全部重写 |
| 手动录入 | 大输入框逐行输入 + 学科/日期/孩子选择 + 实时条数 + 快捷短语 + 批量保存（事务接口） |
| 兼容 | Token 走 `X-Auth-Token` / `?token=` / `Authorization` 三通道；批量接口不可用时自动逐条保存 |

实测（Chromium 390×844 与 1440 桌面）：注册 → 建档 → 三行批量录入 → 看板回显 → 完成勾选 → 编辑回写 → 照片识别降级 → 删除确认全部通过，JS 错误 0；主包由 872KB 降至约 200KB（gzip 约 80KB）。
